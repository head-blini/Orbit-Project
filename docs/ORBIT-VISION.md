# Orbit — 최상위 제품 비전

- 상태: 사용자 확정
- 기준일: 2026-10-28
- 문서 역할: 제품 정체성과 변경 통제의 최상위 기준

## 1. 변경하지 않을 제품 비전

**Orbit은 누구나 자연어로 목표를 입력하면 다양한 AI 모델·에이전트·Skills·MCP·외부 도구를 활용해 기획, 실행, 협업, 검증, 결과물 생성까지 수행하고, 프로젝트 방향성과 진행 상태를 일관되게 관리하는 범용 AI 작업 자동화 플랫폼이다.**

Orbit은 코딩 전용 도구, 단순 AI 채팅 통합기, AI 실행 로그 뷰어, 특정 제공자 전용 프런트엔드가 아니다. 이런 기능은 제품 비전을 실현하는 구성 요소일 수 있지만 제품 자체의 정의를 대체하지 않는다.

## 2. 사용자 경험의 고정 원칙

1. 사용자는 개발 지식 없이 자연어로 목표를 입력할 수 있다. 코딩·분석·조사·문서·이미지·업무 자동화를 포괄한다.
2. 요구사항 입력 → 기획 모델 선택/추천 → 작업 명세 생성·검토·승인 → 프로젝트 저장·이동 → 실행 모델 선택/추천 → 실행·협업·검증 → 결과물 보존·후속 작업으로 이어진다. 단순 작업에서는 불필요한 단계를 줄일 수 있다.
3. 간편 모드와 고급 모드는 동일한 프로젝트 데이터·권한·실행 기록을 사용한다. 고급 모드에서 단계별 모델·추론 강도·도구·승인 정책을 제어할 수 있다.
4. 프로젝트 목표·제약·승인된 결정과 이유·완료 조건을 버전으로 보존한다. AI의 변경 제안은 사용자 승인 없이 확정 기준을 덮어쓰지 않는다.
5. 프로젝트·작업·실행별 진행 상태, 담당 AI, 마지막 관측 활동, 대기/실패 원인, 결과물, 검증 상태를 보여준다. AI의 완료 선언과 검증 통과를 구분하고 근거 없는 진행률·ETA를 표시하지 않는다.
6. AI 전환 시 승인 기준, 관련 파일·결과물, 결정 이력, 미해결 문제, 검증 증거를 구조화해 인계한다. 모델 내부 상태의 완전한 이전을 약속하지 않는다.
7. 사용량 한도·연결 끊김·재시작 시 상태를 보존하고 중복 실행과 무단 유료 API 전환을 막는다.

## 3. 모델·에이전트 확장성 (추가 확정)

- 사용자가 새 모델·제공자·에이전트 실행기를 직접 등록·수정·비활성화할 수 있는 확장 가능한 Registry를 제공한다.
- 에이전트 실행기(Codex, Claude Code, 기타 CLI), 모델 API/서버(OpenAI 호환 API, Bedrock, Ollama, vLLM 등), 라우팅 게이트웨이, 웹 기반 연동을 구분한다.
- 연결 방식·인증 방식·모델 ID·지원 기능·실행 권한·비용 유형·연결 상태를 분리해 관리한다. 새로운 제공자 추가가 코어 스키마의 반복적인 변경을 요구하지 않도록 어댑터/기능 계약을 사용한다.
- 등록 성공은 실행 가능을 의미하지 않는다. 설치·인증·연결·스트리밍·도구 사용·중단·재개·사용량 등 실제 검증된 기능만 활성화한다. 확인 불가 값은 unknown으로 표시한다.
- 새 모델이 등장해도 기존 프로젝트의 목표와 저장된 결과물이 특정 제공자에 종속되지 않도록 한다.
- Skills·MCP·Plugins는 출처·권한·호환성·보안 검토 후 프로젝트별로 사용한다. 무단 설치, 인증정보 수집, 외부 반출, 유료 API 전환을 허용하지 않는다.

## 4. 변경 통제 규칙

- **비전 고정, 구현 유연:** 새로운 아이디어는 비전에 기여하는지, 기존 기능으로 대체 가능한지, 비용·보안·유지보수·회귀 위험이 적정한지 평가한다.
- 기능 제안은 곧 승인된 범위 변경이 아니다. 추가·제외·우선순위 변경은 영향 분석과 명시적인 사용자 결정으로 기록한다.
- 구현 단계의 축소(MVP/개인 우선)는 제품 정체성의 축소가 아니다. 사내 공유는 실사용 검증 후 검토한다.
- 기존 구현·사용자 데이터·Git 변경사항·보안 경계는 보존한다. 전면 재작성, 파괴적 Git 명령, 무단 배포/Push, 무단 결제·외부 반출을 금지한다.
- 문서 간 충돌 시 이 문서를 **제품 비전**의 우선 기준으로 삼는다. 보안·법률·사용자 명시 승인 조건을 이 문서로 완화할 수 없다. 구체 기능의 최신 승인 명세는 별도 범위 문서에서 관리한다.
- 제품 비전 자체의 변경은 사용자의 **명시적인 비전 변경 승인**과 새 버전 기록 없이는 수행하지 않는다.

## 5. 개발과 실행 역할

- Orbit 제품 개발은 현재 다른 PC에서 Claude Code와 Codex를 함께 활용할 계획이며, 두 도구는 동일한 확정 명세와 별도 Git 작업 공간을 사용한다.
- Orbit 제품이 지원하는 AI 실행기는 특정 개발 도구에 고정되지 않는다. ChatGPT 웹·Codex·Claude Code 연동을 초기 실사용 목표에 포함하며 이후 제공자를 확장한다.
- 기존 AI의 네이티브 실행·협업·검증 기능을 우선 재사용하고 중복 엔진을 불필요하게 구현하지 않는다.

## 6. 첫 실사용 수용 기준

사용자가 자연어로 프로젝트를 생성하고 기획 명세를 승인한 후 선택한 AI로 실행할 수 있다. 다른 AI로 인계해도 확정 기준과 결정 이유가 유지되며, 진행 상태·막힌 이유·검증 결과·산출물을 한곳에서 확인할 수 있다. 코드 작업과 비코드 작업 모두에서 이를 검증한다. 실제 연결을 검증하지 않은 기능은 완료로 표시하지 않는다.
