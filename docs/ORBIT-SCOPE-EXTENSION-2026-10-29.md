## 절대 경계
1. 원본 목표·승인 기준·필수 수용 조건은 개선 에이전트가 임의 변경하지 않는다.
2. 검증 정책·권한·격리·인증·과금·외부 전송·핵심 Scheduler 변경은 자동 자기 승격 금지. 개선 에이전트와 보호 평가/승격 권한은 분리한다.
3. 새 lint/테스트의 생성만으로 개선 완료 처리하지 않는다. 정상·실패 샘플과 보호 회귀 평가에 통과하고 이후 효과를 추적한다.
4. 모델 지정값 ≠ 실제 관측 모델. `unknown`을 임의 보완하거나 같은 모델 다중 Worker를 독립 교차 모델 리뷰로 세지 않는다.
5. Git Worktree는 코드 충돌 격리이지 OS/네트워크 보안 샌드박스가 아니다. 공유 Git 메타데이터 변경과 통합은 직렬화한다.
6. 추가 유료 API, 인증 전환, Push, main 병합, 배포는 이번 승인에 포함하지 않는다. 기존 데이터베이스·미커밋 자료·개인정보 보존.
7. CLI 실제 호출 승인 범위는 **두 구독 CLI 각각 최소 한 번, 임시 비민감 fixture**, 기존 보안 정책 내의 제한된 호출이다. 추가 실호출은 실제 사용량·권한 범위가 명확해야 하며 무제한 호출 승인은 아니다.

## 확장 수용 테스트
- AX01: 3개 독립 작업 중 선행 관계 없는 두 Worker의 실행 시간이 실제 중첩되고, 의존 작업은 기다림.
- AX02: 공유 파일/DB/포트 충돌과 쓰기 소유권 경쟁을 차단하고 통합 시 전체 회귀 재검증.
- AX03: 서버 재시작·중단 응답 유실·quota 소진 이후 동일 요청 중복 실행 없음.
- AX04: mock 또는 stale, 미확인 모델, 단순 형식 체크만으로 최종 완료가 되지 않음.
- AX05: 반복 실패 재현으로 개선 후보를 생성하고 이전 버전보다 오류 검출/회귀 결과가 나아짐을 보호 평가로 검증.
- AX06: 개선안이 검증 무력화나 사용자 목표 변경을 시도하면 차단; 허용된 저위험 개선만 제한 적용 후 철회 가능.
- AX07: 코드 작업 한 건과 비코드 작업 한 건에서 작업 그래프·검증·산출물이 사용자 UI에서 증거와 일치.

## 범위 상태
이 문서는 **승인 범위와 설계**를 정의할 뿐 구현 완료를 주장하지 않는다. 실제 저장소 반영·테스트·실행 증거는 별도 체크포인트에 기록한다.
