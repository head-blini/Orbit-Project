# Source-bound native Codex review

Use the installed official App Server stable schema: `thread/start` then `review/start` with `delivery:inline` and `target:{type:custom,instructions}`. Detached review is deprecated in this schema. Reuse the existing Rpc/CLI restricted launch and denial behavior; do not add an orchestration framework. Root owns shared types, SQLite service, Controller/HTTP, mutual exclusion and integration. Independent agents own the pure diff-input builder, native protocol runner and UI.

- [x] Build a bounded deterministic review payload from the existing sanitized WorkspaceDiff. Reject omitted/binary/oversized/invalid/unsafe input; preview exactly what will be sent. Fingerprint before/after diff collection and recompute on execution. Store hashes and results, not the submitted diff text, in Orbit history.
- [x] Run a separate read-only text-only native session, verify ChatGPT account and effective sandbox/approval/MCP isolation before one inline review turn. Existing restricted CLI arguments keep tools/network/hooks/Goal/subagents disabled. No native main-thread reuse or paid API fallback. Fake-RPC contract tests cover ordering, early/foreign events, output redaction, timeout, interruption and unproven process closure.
- [x] Persist explicit-consent intent/receipt, source/input/preview digests, final review text and exact lifecycle. Completion requires the matching review result and terminal native turn; recompute source digest afterward. Source change becomes stale. Review completion is separate from tests, review approval and merge.
- [x] Add Development preview/consent/start/interrupt/history, currentness and restart recovery. Uncertain native process closure quarantines the workspace until explicit stopped attestation; no auto replay/retry/resume. Use bounded history/quota and show unresolved records before recent completed records.
- [x] Run focused and independent reviews, full tests/type/build and Windows browser recovery checks. Existing browser fixtures keep actual AI disabled; any optional real native smoke requires a separately recorded scope and cannot be claimed from mocks.

Bounds: one review turn and 60-second operation deadline, plus bounded shutdown observation. Subscription/token/quota/remote completion remain unknown unless returned by verified interfaces; no billing cap claim. Orbit sends a sanitized, privacy-checked diff as explicitly previewed text. Native CLI session retention and native-provider transport are outside the Model Hub gateway policy. No test execution, local file access, edits or automatic approval are granted to the reviewer.

This connects a manual native review primitive. The complete Cross Review/Debate/Race/Cooperate/Goal executors and Claude/Gemini adapters remain separate unfinished work.
